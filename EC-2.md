## 🔥 Quick Revision

|---|---|
| EC2 | Virtual server |
| AMI | Template to launch EC2 |
| EBS | Persistent disk |

| Security Group | Instance-level firewall |
| Elastic IP | Static public IP |
| ENI | Virtual network card |
| ALB | HTTP/HTTPS load balancing |
| Target Group | Group of targets |
| Auto Scaling | Add/remove instances automatically |
| Spot | Low-cost, interruptible capacity |
