EC2= (Elatstic Compute Cloud)

Users:
Root = 0
Default = 1 to 999
Local = 1000 to 64000+

Types of Instance:
Memory Based Instance = For Fast Instance .
General Based Instance = To Balance Instance.
Storage  Based Instance = In case of Large Data We Use Storage instance.

Spot Request:
It is used when we need it with 90% off but when aws want it, it directly takes back.

Reserved Instance:
It is used for mainly for a particular time period.

Dedicated Host:
A physical server fully reversed only for you. (Not Shared With Other User).

Elastic Block Store:
In Volume we can Store Data and we can attach to our Server if we want more storage to it.
When you delete the instance, Volume can still exist separetly. 

Snapshot:
We can store server backup in it. You can create a new volume from a snapshot.
